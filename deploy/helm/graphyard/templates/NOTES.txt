Register the dedicated GitHub App with `graphyard github-setup`, then set config.githubRepository,
config.githubAppId, config.githubInstallationId and the GITHUB_PRIVATE_KEY / GITHUB_WEBHOOK_SECRET keys.
{{- end }}

{{- end }}
{{- if .Values.postgresql.enabled }}

The bundled Postgres is an evaluation database on one PersistentVolumeClaim. Point DATABASE_URL at
managed Postgres, with its own backups, before relying on this installation.
{{- end }}
{{- if not .Values.backup.enabled }}

Scheduled logical backups are off (backup.enabled=false). Enable them, or run
`kubectl exec deploy/{{ include "graphyard.fullname" . }} -- node bin/graphyard.mjs db backup /tmp/ledger.json`
before every upgrade. See docs/deployment.md for the upgrade, backup and restore procedure.
{{- end }}
