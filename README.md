# Graphyard

**Turn a fleet of coding agents into an engineering system.** Agents write the code; Graphyard records ownership and evidence and merges only what every gate allowed.

**Start with [From zero to a running Graphyard](docs/setup-from-zero.md)**, the ordered setup checklist.

[Install](docs/install.md) · [How it works](docs/how-graphyard-works.md) · [Onboard a repository](docs/onboarding.md) · [Documentation](docs/README.md)

```sh
node /path/to/graphyard/bin/graphyard.mjs install --provider railway --repo OWNER/REPO --plan   # then --apply
```

**[docs/install.md](docs/install.md) is the primary install path**. Contribute via [AGENTS.md](AGENTS.md) and the [development guide](docs/development.md). Apache 2.0.
