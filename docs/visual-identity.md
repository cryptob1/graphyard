# Graphyard visual identity

For anyone placing the mark, and what colour may never mean.

The mark draws a lowercase **g** as a connected path; three nodes suggest independently owned work joining a delivery flow.

- `web/public/graphyard-symbol.svg`: Pale green, for dark backgrounds
- `web/public/graphyard-symbol-ink.svg`: Dark green, for light backgrounds
- `web/public/favicon.svg`: Simplified mark on an opaque dark rounded square, for browser tabs

All three are self-contained SVGs carrying only a title and basic shapes, under the repository's Apache-2.0 licence; edit the path coordinates directly. Keep clear space of one node diameter, prefer the favicon at small sizes, never stretch or rotate the mark.

The palette is pale green `#c5e69b`, ink `#243923`, dark surface `#111714`. Colour is decorative, never a status indicator: status uses text and accessible UI semantics.
