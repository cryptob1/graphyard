# Graphyard visual identity

The proposed mark draws a lowercase **g** as a connected path. Three visible nodes suggest independently owned work joining a delivery flow; the descending path leaves room for the next step. The symbol is original vector geometry, not a font glyph or a generated bitmap.

## Assets

- `web/public/graphyard-symbol.svg`: pale green for dark backgrounds.
- `web/public/graphyard-symbol-ink.svg`: dark green for light backgrounds.
- `web/public/favicon.svg`: simplified mark on an opaque dark rounded square for browser tabs.

All assets are self-contained SVGs. They contain only a title and basic paths/shapes: no scripts, embedded fonts, external images, remote references or animation. They share the repository's Apache-2.0 license. Edit the path coordinates directly in a vector editor or text editor.

Use the symbol beside the ordinary text wordmark “graphyard.” The wordmark remains real UI text for accessibility and responsive layout. When it sits beside that text, the image has empty alt text to avoid announcing the name twice; standalone uses should supply “Graphyard” as alternative text.

Keep clear space of at least one node diameter around the mark. Prefer the dedicated favicon at small sizes. Do not stretch or rotate it. Use the ink variant on white/light backgrounds and the pale variant on the dark application surface. The symbol is tested visually at 16, 24, 32 and 64 pixels; identity choice still requires the operator's approval under GY-7's acceptance criterion.

The palette uses pale green `#c5e69b`, ink `#243923` and dark surface `#111714`. Color is decorative, not a workflow status indicator. Status must continue to use text and accessible UI semantics.
