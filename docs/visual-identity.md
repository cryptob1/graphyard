# Graphyard visual identity

For anyone placing the mark, and what colour may never mean.

The mark draws a lowercase **g** as a connected path, its three nodes independently owned work joining a delivery flow: `web/public/graphyard-symbol.svg` (pale green, for dark backgrounds), `web/public/graphyard-symbol-ink.svg` (dark green, for light backgrounds) and `web/public/favicon.svg` (the simplified mark on a dark rounded square, for browser tabs). All three are self-contained SVGs under the repository's Apache-2.0 licence; edit the path coordinates directly, keep clear space of one node diameter, prefer the favicon at small sizes, never stretch or rotate the mark.

The palette is pale green `#c5e69b`, ink `#243923`, dark surface `#111714`. Colour is decorative, never a status indicator: status uses text and accessible UI semantics.
