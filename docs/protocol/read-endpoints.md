# Read endpoints

- `GET /healthz` (unauthenticated); `/api/status`: principal, integrations, held/failed jobs, `mergeWriter`, `leadTime` (the dashboard top bar's speed number, GY-1989), clock; no GitHub App, budget or main-guard field (GY-2010), and `/api/github/*` answers 404.
- `GET /api/work-snapshot`: `{work, now}`, `autoDispatch`; settled deliveries `summary: true`; `view=coordination` trims open items, `view=full` exports all; else pages by `cursor` (last number), `pageSize` (≤1000, default 100) → `hasMore`, `nextCursor`. `GET /api/pipeline-timelines`: `{timelines: [{id, key, pipeline}]}` for `master status` `speed`.
- `GET /api/work/ID|KEY`: one item (CLI name resolution); `/api/work`: the fleet (open items whole, settled deliveries summarized), `?pr=N` only the item whose candidate or submission names pull request N (else `[]`); other reads, observation claim: the same.
- `GET /api/interventions?window=7|30|90`: ledger rows (`catalogue`, `catalogued` matches); `patterns[]`: `unlinked` judges `threshold`; `work`: item quoting `N KIND interventions at the STAGE stage`; `accounted`, `causes`, `reworkRounds`; `instances` (newest 100); `underThreshold` (`since`, `days`/`holdDays` 14, `peak`, `projected`; `reach`: `ledger.since`, or truncated, oldest retained insertion; `established` (`reach`+`policy.windowDays`) bounds `since`/`peak`; past `window.to`: `since` null, `projected`=`established`); count-0 rows kept. Uncounted: loop failed-check rework (`SHA:ci:CHECKS`), loop-grounded/criteria-implied/duplicate-planned widenings, routed asks, routable refused asks in bound (needs a live master operator plus a distinct approver-only agent); hand reworks, other widenings count.
- `GET /api/retro`: artefacts (newest first), registries' `standing` revisions; `/api/retro/standing` (any role): applied entries ([`retroStanding`](../operations-reference.md#retro-synthesis), `retroCatalogued`).
- `GET /api/events?work=UUID`: newest first (`graphyard events GY-N --all`); no `work`: whole ledger (operator agents: `decision:approve`). Routine `github.observed`/`heartbeat` rows need `routine=include`; `limit` (300), `cursor` (last `seq`); filter `kind`, `since`, `until`.
- `GET /api/analytics/flow`, `/api/analytics/attribution`: bounded; scan reach `window.covered`/`window.kinds`; `throughput[].covered: false` unread; Merged is Deploy; `stepDwell[].sparse` (n<5); `/drilldown`: metric's kinds (`steps`: gate/merge facts) per filtered item; concurrent duplicates shared.
- `GET /api/deployments`: `POST /api/deployments` observations (`producer`/`admin`; `succeeded`, `failed`, `rolled_back`; never gates).
- `GET /api/tests`, `/api/tests/ID/runs`: case results, paged history; `/api/delegation`, `/api/proof-grants`, `/api/delivery`: slices, live proof authority, release state.
